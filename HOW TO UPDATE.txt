OFFICE EATS — HOW TO UPDATE THE EVENT LIST
============================================

The site is live at:
   https://m-tripp-midtronics.github.io/office-events/

The file events.csv is the source of truth for it:
   https://github.com/m-tripp-midtronics/office-events/blob/main/events.csv

EVENT ROW FORMAT
   Date        YYYY-MM-DD, e.g. 2026-12-05
   Day         Day of the week, e.g. Thursday — for reference only;
               the site calculates this itself from Date, so this
               column doesn't have to be perfect, just keep it
               accurate for anyone reading the spreadsheet directly
   Type        Breakfast or Lunch (spelled exactly like that)
   Start Time  e.g. 11:30 AM
   End Time    optional — leave blank for a single start time,
               fill in for a range like a breakfast window
   Menu        whatever's being served

TWO WAYS TO UPDATE IT

Option A — Edit on GitHub.com directly (no Claude needed)
   1. Open the events.csv link above.
   2. Click the pencil (edit) icon.
   3. Add, change, or delete a row.
   4. Scroll down and click "Commit changes" (commit straight to main).
   The site rebuilds automatically within a minute or two — nothing
   else to do. This is the easiest option for a co-editor who doesn't
   have Claude access to this folder.

Option B — Edit locally in Excel, then ask Claude to push
   1. Open events.csv from this folder (double-click opens it in Excel).
   2. Add, change, or delete a row. Save the file (keep it as .csv —
      if Excel asks, choose "Keep Current Format").
   3. Message Claude (in a session with access to this "Office Events"
      folder) and say something like:
        "Push the events.csv update to GitHub."
      Claude will commit and push the change, which triggers the same
      automatic rebuild.

Either way, both of you can update the list independently.
